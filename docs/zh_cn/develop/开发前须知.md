## 搭建开发环境

0. 如果很久以前 Fork 过本项目，先在自己仓库的 `Settings` 里翻到最下面，删除仓库。

1. 打开 [MaaTOT 主仓库](https://github.com/Coxwtwo/MaaTOT)，`Fork` → `Create fork`。

2. 克隆你 fork 的仓库到本地，并拉取子模块：

   ```bash
   git clone --recurse-submodules <你的仓库 git 链接> -b main
   ```

   注意不要忘记 `--recurse-submodules`，否则 OCR 可能异常。

   如已克隆但发现资源缺失，可运行:

   ```bash
   git submodule update --init --recursive
   ```

3. 安装调试/开发工具
    | 工具 | 简介 |
    |------|------|
    | [Maa Pipeline Support(推荐)](https://marketplace.visualstudio.com/items?itemName=nekosu.maa-support) | VSCode 插件，提供调试、截图、获取 ROI、取色等功能 |
    | [MaaLogAnalyzer(推荐)](https://github.com/MaaXYZ/MaaLogAnalyzer) | 可视化分析基于 MaaFramework 开发应用的日志 |
    | [MFAToolsPlus](https://github.com/SweetSmellFox/MFAToolsPlus) | 跨平台开发工具箱，提供便捷的数据获取和模拟测试方法 |
    | [MaaDebugger](https://github.com/MaaXYZ/MaaDebugger) | 独立调试工具 |
    | [ImageCropper(不推荐)](https://github.com/MaaXYZ/MaaFramework/tree/main/tools/ImageCropper) | 独立截图及获取 ROI 工具 |

    > 推荐使用 VSCode 插件进行开发调试、MaaLogAnalyzer 进行用户日志分析

## 妙妙小工具

`tools/autojson/` 包含自动生成 Pipeline 配置的脚本：

| 文件 | 功能 |
| --- | --- |
| `update_level.py` | 从 `levels.csv` 读取异常副本关卡信息，自动生成 `T_异常副本.json` |
| `levels.csv` | 异常副本关卡数据表（按篇章、角色、材料类型分类） |

`T_异常副本.json` 是项目中最大的任务配置文件，包含所有异常副本关卡的下拉选择结构。关卡数量庞大，手动维护不现实，因此通过 CSV + Python 脚本自动生成。只在异常副本更新时才需要用到此工具。
