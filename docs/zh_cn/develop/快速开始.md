# 快速开始

> 本指南适用于**小改动**（< 50 行、只改一个文件）的场景。如果要添加完整的新功能模块，请先阅读 [开发前须知](./开发前须知.md) 和 [编码规范](./编码规范.md)。

## 前置要求

- 有 GitHub 账号，了解 GitHub 基本操作
- 已安装 Git
- 已安装 VS Code

## 1. Fork 仓库

打开 [MaaTOT](https://github.com/Coxwtwo/MaaTOT)，点击右上角 `Fork` → `Create fork`。

## 2. 克隆到本地

```bash
git clone --recurse-submodules <你的仓库 git 链接> -b main
```

> ⚠️ 不要忘记 `--recurse-submodules`，否则 OCR 可能异常。

## 3. 安装调试工具

安装 VSCode 插件 [Maa Pipeline Support(推荐)](https://marketplace.visualstudio.com/items?itemName=nekosu.maa-support) 进行调试

## 4. 修改你希望修改的文件

常见场景：

- **修改活动节点 OCR 预期结果**：调整 `expected` 字段，修改为最新活动名称。例如 `"expected": ["故城","长燃的薪火"]` 改为 `"expected": [ "[予子]爱","[未术]名"]`

## 5. 测试

使用调试工具测试你的改动是否生效。

## 6. 提交 Pull Request

完成开发后，提交 Pull Request 到 MaaTOT 主仓库。
